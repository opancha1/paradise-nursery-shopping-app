# Paradise Nursery Shopping Application

Paradise Nursery is a React shopping cart application for an online plant shop.

## Project Features

- Browse houseplants organized into three categories.
- Display plant thumbnails, names, descriptions, and prices.
- Add plants to a shopping cart.
- Disable an Add to Cart button after an item is added.
- Dynamically display the number of items in the cart.
- Increase, decrease, and remove cart quantities.
- Calculate item totals and the overall cart total.
- Navigate between Home, Plants, and Cart pages.
- Use Redux Toolkit for shopping cart state management.

## Categories

1. Indoor Plants
2. Succulents
3. Flowering Plants

## Technologies

- React
- Vite
- Redux Toolkit
- React Router
- JavaScript
- CSS
